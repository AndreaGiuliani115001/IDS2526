La strategia di test per HackHub è strutturata per garantire l'integrità della logica di business e la corretta persistenza dei dati.

13.1 Unit Test
I test unitari si focalizzano sull'isolamento dei componenti core utilizzando JUnit 5 e Mockito:
Test dei servizi applicativi: Verifica della logica di orchestrazione (es. UserService, HackathonService).
Test dei domain model: Validazione delle regole di business all'interno degli State Handler (es. verificare che non sia possibile sottomettere progetti in fase di registrazione).

13.2 Integration Test
Repository: Test di persistenza sul database H2 per validare il mapping JPA e l'integrità del file di database locale.
Controller REST: Test degli endpoint API (es. registrazione team) per verificare i codici di stato HTTP e i payload JSON.
Integrazione con servizi esterni: Verifica del corretto funzionamento dei Mock Adapters per i sistemi di pagamento e calendario.
